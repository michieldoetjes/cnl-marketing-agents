# Vertaling: SaaS-begrippen in de skills → Compassion

De marketing-skills zijn geschreven voor softwarebedrijven. Gebruik deze vertaling.

| In de skill | Bij Compassion | Opmerking |
|---|---|---|
| Product | Kindsponsoring (en giften) | |
| Customer / user | Sponsor, donateur, supporter | |
| ICP / personas | Donorsegmenten (focus: Savvy Stewards, Movement Mobilizers) | |
| Signup / trial start | Start sponsor-checkout of donatieflow | `begin_checkout` is géén key event |
| Conversion / purchase | Nieuwe sponsoring of gift | Purchase gaat server-side via payment-webhook |
| Pricing | Vast maandbedrag sponsoring; vrij bedrag giften | Prijsexperimenten alleen na intern akkoord |
| Activation / onboarding | Eerste weken als sponsor: welkom, eerste brief, eerste update | Skill `emails` (welkomstjourney), niet `onboarding` |
| Churn | Opzegging of beëindiging van sponsoring | Skill `churn-prevention` |
| Dunning / failed payments | Storno's en mislukte incasso's (FinDock/Converse) | |
| Upsell / expansion | Tweede kind, extra gift | Alleen respectvol, nooit bij twijfel over opzegging |
| Revenue | Eenmalig (€) en terugkerend (€/maand) apart | Nooit optellen |
| Lead | Iemand die interesse toont (nieuwsbrief, event, QR-code) | |
| Sales team | Relatiebeheer (grote gevers, kerken) | |
| Competitors | Andere goede doelen | Geen negatieve vergelijkingen |
| Launch | Campagnestart | |
| FTC / CAN-SPAM / TCPA | AVG, Telecommunicatiewet, Reclame Code, CBF | |
